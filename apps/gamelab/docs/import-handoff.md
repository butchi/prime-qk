## 検証結果

- `npm run build`: DB・GAME LAB・Kantan・Console・Catalog の全ワークスペースで成功。
- `npm run test --workspace=@prime-qk/gamelab`: 1,096件中1,062件成功、34件失敗。
  取り込み元でも同じ34件が失敗することを確認した。いずれも Natural KK の派生ルールと
  古い素数大富豪用テストの期待値の不一致で、内訳は `primeDaifugo.test.ts` が31件、
  `ruleValues.test.ts` が3件。ルール・期待値の変更は次の作業で確認する。
- テストはファイルを順次実行する。並列実行では CPU 探索の時間制限による失敗も再現した。
- localhost の本番ビルドでゲーム一覧と6ゲームの起動を確認。
  一覧からの移動、九九かけ 99 のカード選択・出札、九九大富豪のドローと CPU 応答、
  九九 Reduce のチェーン種別選択、Natural KK の説明ダイアログ、一覧への戻りを確認した。
- OGP は1280×800の SVG と PNG、favicon は SVG と ICO をアプリ内で管理する。

## 公開時の作業

この取り込みでは外部公開や Cloudflare の設定変更は行わない。
公開前に変更をコミットし、[アプリの README](../README.md) の設定で

`gamelab.primeqk.butchi.jp`。`index.html` のメタ情報と OGP 画像もこの予定値を使用する。
